# Nexora Git — Product Identity

## Product name

**Nexora Git**

Repository: `Gh0stDeveloper/Nexora-Git`

Recommended Android application ID:

```text
com.nexora.git
```

Internal project name: `NexoraGit`

Release artifact convention: `NexoraGit-v<version>.apk`

## Positioning

Nexora Git is an independent, open-source Git and GitHub client for Android focused on developers who work from mobile devices.

Primary positioning line:

> A complete mobile Git workspace for Android.

Secondary description:

> Code, commit, branch, push, review and manage complete repositories directly from your phone.

## Brand rules

The product must use its own visual identity.

Do not:

- use the GitHub logo or Octocat as the Nexora Git application icon;
- imply that Nexora Git is an official GitHub application;
- copy GitHub Mobile's interface pixel-for-pixel;
- name releases in a way that suggests official GitHub ownership.

Acceptable wording includes "GitHub client for Android", "Works with GitHub", "GitHub integration" and "Sign in with GitHub".

## Visual direction

- compact information density;
- strong hierarchy;
- clean repository/file surfaces;
- light, dark and AMOLED modes;
- vector iconography;
- no emoji used as functional icons;
- edge-to-edge layouts with correct system insets;
- mobile-first controls and bottom sheets;
- tablet/foldable master-detail layouts.

## Icon direction

Use an original abstract source-control symbol with subtle Nexora/N geometry. Do not use an Octocat silhouette. The final asset should support adaptive and monochrome Android icons.
