# Nexora Git 1.0.0-beta.1

First public qualification build for Nexora Git.

## Included

- real local Git engine based on libgit2;
- GitHub App OAuth with PKCE and HTTPS App Link callback;
- repository browsing, editing and project workspaces;
- Issues, Pull Requests, Actions and Releases;
- durable clone/fetch/pull/push/LFS/import/sync work;
- EN and ES-MX application localization;
- System, Light, Dark and AMOLED themes;
- SBOM, checksums, build provenance and published signing identity.

## Qualification status

This is a beta, not the stable 1.0.0 release. Real-device release qualification, store screenshots, accessibility verification and production-environment validation remain release gates.

Report defects through the GitHub issue tracker. Do not post secrets, access tokens or private repository data.
