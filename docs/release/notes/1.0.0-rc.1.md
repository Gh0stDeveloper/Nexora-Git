# Nexora Git 1.0.0-rc.1

Release candidate for Nexora Git 1.0.0.

This candidate is intended for the complete production qualification matrix: clean install, authentication, multiple accounts, public/private repositories, clone/import, editor, Git network operations and conflicts, Issues, Pull Requests, Actions, Releases, offline/process-death behavior, low storage, network interruption, EN/ES, themes, TalkBack and performance.

No stable 1.0.0 tag may be created from this candidate until the qualification record is APPROVED and every required gate is satisfied.
