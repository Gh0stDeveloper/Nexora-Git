The status may be changed to `APPROVED` only after the exact signed RC identified above has passed the required real-device matrix. Copy this file to `docs/release/qualifications/X.Y.Z.md` for the version being promoted.

## Required qualification matrix

- [ ] Clean install
- [ ] Login and logout
- [ ] Multiple accounts
- [ ] Public and private repositories
- [ ] Clone and import
- [ ] Editor save
- [ ] Commit pull push
- [ ] Conflict workflow
- [ ] Issues
- [ ] Pull Requests
- [ ] Actions
- [ ] Releases
- [ ] Offline reopen
- [ ] Process death
- [ ] Low storage
- [ ] Network interruption
- [ ] English and Spanish
- [ ] Theme switching
- [ ] TalkBack

## Evidence

Record device/Android versions, RC artifact SHA-256, signing fingerprint, workflow URLs, defects discovered and retest results. Do not mark a row complete based only on source review.
